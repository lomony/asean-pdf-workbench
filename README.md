# ASEAN PDF Workbench (unofficial)
Self-hosted copy of the [PDFCraft](https://github.com/storytold/pdfcraft) 0.6.0 web build in `app/`, rebuilt from the v0.6.0 tag with one change: the "Join the ArtCraft community" Discord box is removed from the app home screen (`patches/remove-discord-box.patch`, built with `trunk build --release`) with a simple landing page for ASEAN Secretariat colleagues. Files are processed locally in the browser.
